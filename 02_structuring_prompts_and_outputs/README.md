# Group 2: Structuring Prompts & Outputs

**Modules:** 3, 6

Both modules are about shape. Module 3 structures what goes *in* — delimiters, XML tags, few-shot examples. Module 6 structures what comes *out* — schemas, JSON, structured data. Few-shot examples plus a schema is the most reliable combination in the course.

| Order | Module | Topic | Prerequisite |
|-------|--------|-------|--------------|
| 1st | [Module 3: Clarity, Structure & Few-Shot](./module3/) | Delimiters, XML tags, few-shot example design | Module 2 |
| 2nd | [Module 6: Output Control & Structured Data](./module6/) | Schema-first prompting, JSON mode, few-shot extraction | Module 3 |

**Time:** ~55-65 min of lesson reading, plus labs and exercises.
