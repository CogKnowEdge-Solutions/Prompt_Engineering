# Reusable Exercise Patterns

*A course-wide reference — the recurring exercise formats used across Modules 1-11.*

Every module's Exercises and Challenge files draw from the same small set of exercise patterns. Knowing them explicitly is useful if you're building additional practice material, adapting this course, or want to recognize the underlying skill each exercise type is actually testing.

---

## The Seven Patterns at a Glance

| # | Pattern | What it tests | Used in |
|---|---------|---------------|---------|
| 1 | Fill-in-the-Pattern | Applying a structural template to a new situation | Modules 1, 2, 5, 6 |
| 2 | Fix-the-Prompt | Diagnosing why a prompt fails before rewriting it | Modules 1, 3, 4 |
| 3 | Before/After Comparison | Attributing an output change to a specific technique | Modules 2, 4, 10 |
| 4 | Constraint Challenge | Precision against checkable format/length/content rules | Modules 3, 6, 7 |
| 5 | Red-Team / Patch Pair | The full attack-diagnose-patch-verify cycle | Module 8; Module 11 capstone (Red-Team Report) |
| 6 | Rubric Scoring | Evaluation: judging output quality against a rubric | Module 9; Module 11 capstone (Eval Report) |
| 7 | From Scratch | Synthesis: selecting and combining techniques unprompted | Module 5; most module Challenges |

---

## 1. Fill-in-the-Pattern

**Format:** A template with blanks the learner completes for a given scenario.

**What it tests:** Whether the learner can apply a structural pattern (a prompt template, a schema, an XML structure) to a *new* concrete situation — not just recite the template.

**Used in:** Modules 1, 2, 5, 6.

---

## 2. Fix-the-Prompt

**Format:** A broken or vague prompt the learner must diagnose and rewrite.

**What it tests:** Diagnostic skill — can the learner name *why* something fails before fixing it, rather than producing a better-sounding version by instinct.

**Used in:** Modules 1, 3, 4.

---

## 3. Before/After Comparison

**Format:** The learner applies one specific technique to an existing prompt, runs both versions, and explains what changed and why.

**What it tests:** Whether the learner can attribute a specific output change to a specific technique, rather than treating improvement as a black box.

**Used in:** Modules 2, 4, 10.

---

## 4. Constraint Challenge

**Format:** The learner must hit specific, checkable constraints (format, length, content rules) rather than just producing "a good answer."

**What it tests:** Precision — many prompts fail not on quality but on missing an explicit, checkable requirement.

**Used in:** Modules 3, 6, 7.

---

## 5. Red-Team / Patch Pair

**Format:** The learner attempts to break a given prompt, then patches their own successful attack and re-tests it.

**What it tests:** The full attack-diagnose-patch-verify cycle, not just attack recognition in isolation.

**Used in:** Module 8 (and the Module 11 capstone's Red-Team Report deliverable).

---

## 6. Rubric Scoring

**Format:** The learner scores sample outputs against a defined rubric, rather than writing a prompt themselves.

**What it tests:** Evaluation skill specifically — judging output quality is a distinct skill from producing it, and this pattern isolates that skill for practice.

**Used in:** Module 9 (and the Module 11 capstone's Eval Report deliverable).

---

## 7. From Scratch

**Format:** No template provided — just a stated goal, with the learner designing the full prompt using everything covered so far.

**What it tests:** Synthesis — can the learner select and combine techniques appropriately without being told which one to use, the actual skill this course is building toward.

**Used in:** Module 5, and as the default shape of most module Challenges.

---

## Difficulty Progression

These patterns roughly scale in difficulty in the order listed above: Fill-in-the-Pattern and Fix-the-Prompt are the most scaffolded (Modules 1-3), while Red-Team/Patch Pair, Rubric Scoring, and From Scratch require synthesizing multiple prior modules and appear more heavily from Module 5 onward. The Module 11 capstone is effectively a single, large-scale "From Scratch" exercise that also incorporates Red-Team/Patch Pair and Rubric Scoring as full deliverables rather than short exercises.
