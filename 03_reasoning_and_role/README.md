# Group 3: Reasoning & Role

**Modules:** 4, 5

Two deep dives on the techniques Module 2 only previewed: how you make the model *think* (CoT, self-consistency, tree-of-thought, least-to-most) and who you make it *be* (role and context setting). Both are prompt-only levers — contrast with Group 4, where the lever is an API parameter.

| Order | Module | Topic | Prerequisite |
|-------|--------|-------|--------------|
| 1st | [Module 4: Reasoning Techniques](./module4/) | CoT revisited, self-consistency, tree-of-thought, least-to-most | Module 2 |
| 2nd | [Module 5: Role & Context Setting](./module5/) | How role prompting works, over-trust risk, when to skip the persona | Module 2 |

**Time:** ~60-70 min of lesson reading, plus labs and exercises.
